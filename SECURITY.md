# Security policy

## Reporting a vulnerability

Do not open a public issue for vulnerabilities, unsafe field writes, or profile-data exposure. Use GitHub's **Report a vulnerability** flow in the repository Security tab so details remain private while a fix is prepared.

Include the affected Chrome version, FormPilot revision, reproduction steps, and a synthetic fixture. Do not include real profile values, credentials, or sensitive form data.

## Supported version

Security fixes target the latest revision on the default branch while FormPilot is in early preview.
